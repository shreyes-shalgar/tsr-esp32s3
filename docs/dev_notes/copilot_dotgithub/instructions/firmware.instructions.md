---
name: Embedded C rules
description: Rules for the Zephyr application and the int8 runtime
applyTo: 'src/qemu_app/**/*.{c,h}'
---

- C99. No dynamic allocation anywhere in the inference or receive path — no
  `malloc`, `calloc`, `realloc`, or VLAs.
- No floating point in the inference path. The only permitted float is the
  output-side softmax used to report confidence, which runs over 17 values.
- `int32_t` accumulators in convolution. Do not widen to `int64_t` there; it is
  slower and unnecessary. The `int64_t` in the fully-connected requantisation is
  deliberate and required for bit-exactness.
- Every buffer size comes from a generated `#define` in `tsr_model_data.h`.
  Never hard-code a size that the exporter computes.
- `tsr_model_data.c` is generated by `src/export_c_model.py`. Do not hand-edit
  it; change the exporter and regenerate.
- Comment *why*, not *what*. The valuable comments in this file explain
  non-obvious decisions — the two different TFLite rounding rules, why RX is
  polled rather than interrupt-driven. Preserve those comments; someone will
  otherwise "fix" the code they protect.
- Build clean under `-Wall -Wextra`. A new warning is a defect.
- Anything printed on the UART is part of a protocol contract. Adding a debug
  line between `RECEIVED` and `PREDICTION` corrupts the evaluators' inference
  timing. Use a separate build-time flag if you need tracing.
